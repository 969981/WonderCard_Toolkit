# i18n / Localization (v0.4)

## Nine supported UI languages

| Tag | Label | UI coverage |
|---|---|---|
| zh-CN | 简体中文 | 175/175 |
| zh-TW | 繁體中文 | 175/175 |
| en | English | 175/175 |
| ja | 日本語 | 175/175 |
| fr | Français | 175/175 |
| de | Deutsch | 175/175 |
| it | Italiano | 175/175 |
| es | Español | 175/175 |
| ko | 한국어 | 175/175 |

Text in `web/i18n.js` is UI-only. The language selector persists locally when storage is available. It does **not** alter language IDs, trainer names, original card titles, raw bytes, JSON snapshots, ISO date encoding or audit CSV identifiers. Browser locale normalization recognizes e.g. fr-FR, de-DE, es-ES, ko-KR, with `zh-TW` and `zh-Hant` mapped to Traditional Chinese.

Natures retain canonical index order (0..24); translated labels are a presentation layer, never encoded in the Wonder Card. Review localized Pokémon terminology with native speakers/upstream game strings before calling the translations official. New languages and any additional labels must pass `node scripts/check_locales.js`; placeholder tokens must exactly match the source dictionary.

The extended format viewer uses read-only status banners in every language. Unknown and unsupported strings must never be interpreted as HTML. Text insertions must use `textContent` or HTML escaping.
